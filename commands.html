창 열기 — 여기서부터

아래 모든 명령은 PowerShell 창에서 칩니다. 그리고 창이 두 개 필요합니다 — 하나는 라마를 띄워 두는 용도, 하나는 실제로 명령을 치는 용도입니다.

  1. 작업 폴더에서 창 열기

    탐색기로 폴더에 들어간 뒤 주소창에 powershell 을 치고 Enter. 그 폴더에서 바로 열립니다. Shift+우클릭 → “여기에 PowerShell 창 열기” 도 같습니다.

    # 이미 열린 창에서 옮겨갈 때
cd D:\workspace_raraavis\arduino_project00

# 지금 어디인지 · 무슨 파일이 있는지
pwd
ls

  2. 첫 번째 창 — 라마를 띄워 둡니다

    이 창은 그대로 두세요. 닫으면 팔이 말을 못 알아듣습니다.

    ollama serve

# 새 창을 열어서 모델이 있는지 확인
ollama list        llama3.1:8b 가 보여야 합니다

  3. 두 번째 창 — 여기서 명령을 칩니다

    1번처럼 작업 폴더에서 새 창을 하나 더 엽니다. 파이썬이 맞는지 먼저 확인하세요.

    py -0              설치된 파이썬 목록
py -3.12 -V        3.12.x 가 나와야 합니다

    python 이 아니라 py -3.12 로 실행해야 합니다. python 은 3.14로 가고, 거기엔 torch가 없습니다.

  4. 포트 번호 확인

    USB를 다른 자리에 꽂으면 번호가 바뀝니다. 기본값은 COM4이고, 다르면 --port 로 알려줍니다.

    [System.IO.Ports.SerialPort]::GetPortNames()

  5. 실행

    py -3.12 checkup.py --deep          먼저 온전한지
py -3.12 llm_arm_bridge.py --port COM4

    가상환경(.venv)을 만드셨다면 py -3.12 대신 .venv\Scripts\python 을 씁니다.

창에서 알아두면 편한 것

  • Tab파일 이름 자동완성 — py -3.12 ha 까지 치고 Tab
  • ↑이전에 친 명령 다시 꺼내기
  • Ctrl+C지금 도는 것 중단
  • 우클릭붙여넣기 (PowerShell에서는 이게 붙여넣기입니다)
  • Ctrl+휠글꼴 크기 — 시연 전에 키워 두세요
  • cls화면 지우기

한글이 깨져 보이면

옛 cmd 창에서 가끔 그렇습니다

chcp 65001

PowerShell을 쓰시면 대개 문제없습니다. Windows Terminal이 있다면 그쪽이 더 낫습니다.

  • 그 상태로 기다리세요 시간을 안 말하면 홈으로 안 돌아갑니다

특수 입력

언어모델을 거치지 않습니다

  • stop즉시 홈으로 — 시연 중 가장 쓸 일이 많습니다
  • bad직전 동작이 이상했음 → 마지막 기록 삭제
  • !명령아두이노에 직접 전송 (아래 표)
  • quit종료 (exit, 종료 도 됩니다)

직접 명령 !

보정·디버깅용. 각도 한계는 펌웨어가 여전히 강제합니다

!S 0 90        관절 0을 90도로
!P 90 60 120 90 60   다섯 관절 동시에
!GRIP 1        집게 닫기 (0=열기)
!SPEED 5       속도 1~10
!WAIT 1000     대기 (한 번에 최대 5000)
!HOME          홈 자세
!GET           현재 각도 조회

손 추적 중 키 조작

창을 클릭해 활성화한 뒤

  • h홈 자세
  • i좌우 방향 뒤집기
  • g집게 제어 켜기 / 끄기

음성 중 조작

스페이스를 누르고 있는 동안만 듣습니다

  • space누르고 말하기 → 손을 떼면 끝
  • Enter들린 문장 그대로 실행
  • e글자로 고쳐서 실행
  • r / n다시 말하기 / 버리기
  • go이후 확인 없이 바로 실행 (ask 로 복귀)

점검과 보정

무엇이 잘못됐는지 모를 때 추측하지 말고 이쪽부터 돌리세요. 이 도구들이 이 프로젝트의 진짜 줄거리입니다.

실행무엇을 재는가옵션
checkup.py 작업공간이 온전한지 — 기능별로 빠진 것과 그 영향 --deep 모듈 불러오기까지
vision_check.py 카메라와 색 범위 --list --diag --probe
mp_check.py mediapipe가 실제로 도는지 · 스마트 앱 제어 상태 —
voice_check.py 마이크 · GPU · 받아쓰기 --stt 받아쓰기까지 · --mic
look_at.py 파란 물체 보고 각도만 계산 (팔은 안 움직임) 인자에 색 이름
colors.py 아는 색 목록과 HSV 범위 —
calibrate_point.py 가리키기 보정 — 화면 x ↔ 베이스 각도 --fresh 처음부터 · --out
check_dataset.py 학습 데이터의 모순 · 부호 · 방향 · 시간 파일 이름을 인자로
지금 가리키기 보정은 화면의 31%만 덮습니다 (x 378~576, 오른쪽). 그 밖에서는 직선을 늘여 추정하며, 그럴 때 ※ 보정 구간 밖이라 추정값입니다 라고 알려줍니다. calibrate_point.py 로 왼쪽과 가운데에 3~4점만 더 찍으면 화면 전체가 쓸 만해집니다.

막혔을 때

전부 우리가 실제로 겪은 것들입니다. 증상보다 진짜 원인이 엉뚱한 데 있는 경우가 많았습니다.

창에 뜨는 말진짜 원인할 일
'py' 용어가 ... 인식되지 않습니다 파이썬이 없거나 PATH에 없음 python -V 로 확인 · python.org에서 재설치 시 Add to PATH 체크
No module named 'torch' python 이 3.14로 감 py -3.12 로 실행
could not open port 'COM4' 다른 창이 포트를 잡고 있음 아두이노 IDE 시리얼 모니터 · 다른 파이썬 창 닫기
404 ... /api/chat Ollama가 안 떠 있음 첫 번째 창에서 ollama serve
카메라를 열 수 없습니다 윈도우 카메라 앱이 점유 중 앱을 닫고 vision_check.py --diag
WinError 4551 스마트 앱 제어가 서명 없는 DLL을 막음 Windows 보안 → 앱 및 브라우저 컨트롤 → 스마트 앱 제어 끄기
